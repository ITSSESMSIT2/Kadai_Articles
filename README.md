# 課題2 記事検索（Qiita）

キーワードから Qiita の記事を検索し、一覧表示・詳細モーダル表示ができる記事検索アプリです。
HTML / CSS / バニラ JavaScript のみで実装しています（フレームワーク・ビルド不要）。

## 機能

- **記事の検索**: キーワード（必須）を入力し、Qiita API から該当記事を最大20件取得して一覧表示
- **状態表示**: 検索中 / 該当なし（0件）/ エラーの状態を画面に切り替え表示
- **記事一覧**: 著者・タイトル・タグ・いいね数・作成日をカード形式で表示
- **詳細モーダル**: カードをクリックすると詳細を取得し、本文・統計・投稿/更新日をモーダルで表示（Qiitaで開く導線あり）
- **モーダルを閉じる**: 閉じるボタン / 背景（オーバーレイ）クリック / Esc キー

## 使い方

ビルドやサーバーは不要です。`index.html` をブラウザで直接開くだけで動作します（記事の取得に通信が必要なため、ネット接続が必要です）。

```bash
open index.html
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面のマークアップ（検索フォーム・検索結果・詳細モーダル） |
| `app.css` | スタイル。`:root` にデザイントークン（色・余白・角丸など）を定義 |
| `app.js` | 記事の検索・一覧描画・詳細取得・モーダル開閉のロジック |
| `heart.svg` | いいね数のアイコン |

## 実装メモ

- 記事の取得は Qiita API v2（`GET /items`・`GET /items/{id}`）を `fetch` で呼び出しています。
- キーワードは `encodeURIComponent` でエスケープし、URL に埋め込んでいます。
- `fetch` は HTTP 400 / 500 でも例外を投げないため、`res.ok` を確認して失敗を判定しています。
- 一覧は軽さ重視でメタ情報のみを表示し、本文（`rendered_body`）は詳細モーダルでのみ描画します。
- 詳細本文は Qiita 側で整形済みの `rendered_body` に限って `innerHTML` で描画し、その他のユーザー入力は `textContent` で扱っています（XSS 対策）。
- 一覧のクリックはリスト要素へのイベント委譲で処理し、`data-id` から記事 ID を取得しています。
- 取得したデータはメモリ上のみで保持します（リロードすると消えます）。
